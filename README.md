# 🌐 Portfolio Website

A simple and responsive personal portfolio website built to showcase my skills, projects, and contact information.

## 🚀 About

This portfolio was created as a beginner web development project to practice building responsive web pages using modern frontend technologies.

The website includes:

* Home Section
* About Me
* Skills
* Projects
* Contact Section

## 🛠️ Technologies Used

* HTML5
* CSS3
* Bootstrap 5
* JavaScript (ES6)

## ✨ Features

* Responsive Design
* Smooth Navigation
* Clean User Interface
* Project Showcase
* Contact Information
* Mobile Friendly

## 📂 Project Structure

```text
Portfolio/
```

## 💻 Getting Started

1. Clone the repository

```bash
git clone https://github.com/asGithub09/portfolio.git
```

2. Open the project folder.

3. Open `index.html` in your browser.
